# 🔄 Миграция на оптимизированную сборку

> Для разработчиков, которые работали с проектом до 2026-04-03

---

## Что изменилось

Сборка стала **в 12-30 раз быстрее**. Изменение header/стилей теперь занимает 2-5 сек вместо 60 сек.

---

## 📋 Что нужно сделать

### 1. Обновить зависимости

```bash
# Удалить старые зависимости
rm -rf node_modules package-lock.json

# Установить новые
npm install
```

### 2. Очистить кэш

```bash
# Удалить старый build и кэш
rm -rf build .webpack-cache

# Пересобрать проект
npm run build
```

### 3. Проверить Node.js версию

```bash
node -v
# Должно быть >= 22.0.0
```

Если версия старше:
- **Windows:** Скачать с [nodejs.org](https://nodejs.org/)
- **macOS/Linux:** Использовать `nvm install 22`

## 🐛 Если что-то не работает

### Проблема: Изменения не применяются

```bash
# Очистить кэш и пересобрать
rm -rf build .webpack-cache
npm run dev
```

### Проблема: Ошибки при установке зависимостей

```bash
# Обновить npm
npm install -g npm@latest

# Переустановить зависимости
rm -rf node_modules package-lock.json
npm install
```

### Проблема: Старая версия Node.js

```bash
# Проверить версию
node -v

# Если < 22.0.0, обновить:
# Windows: скачать с nodejs.org
# macOS/Linux: nvm install 22
```
