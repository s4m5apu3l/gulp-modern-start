# Генерация Favicons

## Рекомендуемый способ: RealFaviconGenerator

Используйте онлайн-сервис [RealFaviconGenerator](https://realfavicongenerator.net/) для генерации всех необходимых favicons.

### Преимущества

- ✅ Генерирует все необходимые форматы и размеры
- ✅ Оптимизирует для всех платформ (iOS, Android, Windows, macOS)
- ✅ Создает правильный HTML код
- ✅ Генерирует Web App Manifest
- ✅ Бесплатно и без регистрации

## Способ 1: Онлайн-генератор (рекомендуется)

### Шаг 1: Подготовка исходного изображения

1. Создайте SVG или PNG изображение размером минимум **512x512px**
2. Убедитесь что изображение **квадратное**
3. Используйте **прозрачный фон** если нужно
4. Сохраните как `favicon-master.svg` или `favicon-master.png`

### Шаг 2: Генерация через сайт

1. Откройте https://realfavicongenerator.net/
2. Нажмите **"Select your Favicon image"**
3. Загрузите ваше изображение
4. Настройте параметры для каждой платформы:

#### iOS Web Clip
- Выберите стиль (Background and margin / No change)
- Настройте цвет фона если нужно
- Настройте отступы

#### Android Chrome
- Выберите стиль (Shadow / No change)
- Настройте Theme color
- Укажите название приложения

#### Windows Metro
- Выберите цвет плитки
- Настройте стиль иконки

#### macOS Safari
- Настройте цвет для pinned tab
- Выберите стиль

#### Favicon для браузеров
- Обычно оставляют "No change"

5. Прокрутите вниз и нажмите **"Generate your Favicons and HTML code"**
6. Нажмите **"Favicon package"** для скачивания архива

### Шаг 3: Установка в проект

1. Распакуйте скачанный архив
2. Скопируйте все файлы в `src/assets/favicons/`

```bash
# Пример структуры после копирования
src/assets/favicons/
├── android-chrome-192x192.png
├── android-chrome-512x512.png
├── apple-touch-icon.png
├── browserconfig.xml
├── favicon-16x16.png
├── favicon-32x32.png
├── favicon.ico
├── mstile-150x150.png
├── safari-pinned-tab.svg
└── site.webmanifest
```

3. Скопируйте HTML код из генератора
4. Вставьте в `<head>` вашего layout файла (`src/markup/layouts/default.pug`)

### Шаг 4: Добавление HTML кода в Pug

Откройте `src/markup/layouts/default.pug` и добавьте в секцию `head`:

```pug
head
    meta(charset="utf-8")
    meta(name="viewport" content="width=device-width, initial-scale=1")
    
    //- Favicons (generated by RealFaviconGenerator.net)
    link(rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png")
    link(rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png")
    link(rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png")
    link(rel="manifest" href="/site.webmanifest")
    link(rel="mask-icon" href="/safari-pinned-tab.svg" color="#5bbad5")
    meta(name="msapplication-TileColor" content="#da532c")
    meta(name="theme-color" content="#ffffff")
    
    title= title
```

### Шаг 5: Обновление site.webmanifest

Откройте `src/assets/favicons/site.webmanifest` и настройте под ваш проект:

```json
{
    "name": "Название вашего приложения",
    "short_name": "Короткое название",
    "icons": [
        {
            "src": "/android-chrome-192x192.png",
            "sizes": "192x192",
            "type": "image/png"
        },
        {
            "src": "/android-chrome-512x512.png",
            "sizes": "512x512",
            "type": "image/png"
        }
    ],
    "theme_color": "#ffffff",
    "background_color": "#ffffff",
    "display": "standalone"
}
```

### Шаг 6: Проверка

1. Запустите dev сборку: `npm run dev`
2. Откройте браузер и проверьте:
   - Favicon отображается во вкладке
   - Нет ошибок в консоли
3. Проверьте на мобильных устройствах:
   - iOS: Добавьте на главный экран
   - Android: Добавьте на главный экран

## Способ 2: Gulp плагин (для автоматизации)

Если вам нужна автоматическая регенерация favicons при изменении исходного файла, используйте Gulp плагин.

### Установка

```bash
npm install --save-dev @realfavicongenerator/gulp-real-favicon
```

### Создание задачи

Создайте файл `gulp/tasks/favicons.mjs`:

```javascript
/**
 * Favicons
 * 
 * Автоматическая генерация favicons через RealFaviconGenerator API
 */

import { src, dest } from 'gulp'
import realFavicon from '@realfavicongenerator/gulp-real-favicon'
import fs from 'fs'

import config from '../config.mjs'

const FAVICON_DATA_FILE = 'faviconData.json'

// Генерация favicons
export const generateFavicon = done => {
  realFavicon.generateFavicon({
    masterPicture: `${config.src.assets.favicons}/favicon-master.svg`,
    dest: config.src.assets.favicons,
    iconsPath: '/',
    design: {
      ios: {
        pictureAspect: 'backgroundAndMargin',
        backgroundColor: '#ffffff',
        margin: '14%',
        assets: {
          ios6AndPriorIcons: false,
          ios7AndLaterIcons: false,
          precomposedIcons: false,
          declareOnlyDefaultIcon: true
        }
      },
      desktopBrowser: {
        design: 'raw'
      },
      windows: {
        pictureAspect: 'whiteSilhouette',
        backgroundColor: '#da532c',
        onConflict: 'override',
        assets: {
          windows80Ie10Tile: false,
          windows10Ie11EdgeTiles: {
            small: false,
            medium: true,
            big: false,
            rectangle: false
          }
        }
      },
      androidChrome: {
        pictureAspect: 'shadow',
        themeColor: '#ffffff',
        manifest: {
          name: 'Your App Name',
          shortName: 'App',
          display: 'standalone',
          orientation: 'notSet',
          onConflict: 'override',
          declared: true
        },
        assets: {
          legacyIcon: false,
          lowResolutionIcons: false
        }
      },
      safariPinnedTab: {
        pictureAspect: 'silhouette',
        themeColor: '#5bbad5'
      }
    },
    settings: {
      scalingAlgorithm: 'Mitchell',
      errorOnImageTooSmall: false,
      readmeFile: false,
      htmlCodeFile: false,
      usePathAsIs: false
    },
    markupFile: FAVICON_DATA_FILE
  }, done)
}

// Проверка актуальности favicons
export const checkFaviconUpdate = done => {
  const currentVersion = JSON.parse(fs.readFileSync(FAVICON_DATA_FILE)).version
  
  realFavicon.checkForUpdates(currentVersion, err => {
    if (err) {
      throw err
    }
    done()
  })
}
```

### Добавление в gulpfile.mjs

```javascript
import { generateFavicon, checkFaviconUpdate } from './gulp/tasks/favicons.mjs'

export const favicon = generateFavicon
export const faviconCheck = checkFaviconUpdate
```

### Использование

```bash
# Генерация favicons
gulp favicon

# Проверка обновлений
gulp faviconCheck
```

### Автоматическая инжекция HTML кода (опционально)

Если хотите автоматически вставлять HTML код в layout:

```javascript
// В gulp/tasks/favicons.mjs добавить:

export const injectFaviconMarkups = () => {
  return src(['src/markup/layouts/*.pug'])
    .pipe(realFavicon.injectFaviconMarkups(
      JSON.parse(fs.readFileSync(FAVICON_DATA_FILE)).favicon.html_code
    ))
    .pipe(dest('src/markup/layouts'))
}
```

**Примечание:** Автоматическая инжекция в Pug может работать некорректно, рекомендуется вставлять HTML код вручную.

## Способ 3: Ручная генерация (не рекомендуется)

Если по какой-то причине не можете использовать онлайн-генератор или Gulp плагин, можно создать favicons вручную:

### Необходимые размеры

```
favicon.ico          - 16x16, 32x32, 48x48 (multi-size ICO)
favicon-16x16.png    - 16x16
favicon-32x32.png    - 32x32
apple-touch-icon.png - 180x180
android-chrome-192x192.png - 192x192
android-chrome-512x512.png - 512x512
mstile-150x150.png   - 150x150
safari-pinned-tab.svg - SVG (monochrome)
```

### Инструменты

- **ImageMagick** - для конвертации и ресайза
- **Inkscape** - для работы с SVG
- **GIMP** - для ручного редактирования

### Команды ImageMagick

```bash
# Создание PNG разных размеров
convert favicon-master.png -resize 16x16 favicon-16x16.png
convert favicon-master.png -resize 32x32 favicon-32x32.png
convert favicon-master.png -resize 180x180 apple-touch-icon.png
convert favicon-master.png -resize 192x192 android-chrome-192x192.png
convert favicon-master.png -resize 512x512 android-chrome-512x512.png

# Создание ICO файла
convert favicon-16x16.png favicon-32x32.png favicon.ico
```

**Не рекомендуется:** Этот способ требует много ручной работы и не гарантирует оптимальный результат.

## Проверка результата

### Онлайн-инструменты

1. **Favicon Checker**
   - https://realfavicongenerator.net/favicon_checker
   - Проверяет все форматы и платформы

2. **Favicon.io**
   - https://favicon.io/
   - Альтернативный генератор

### Локальная проверка

```bash
# Проверить что все файлы на месте
ls -la src/assets/favicons/

# Должны быть:
# - favicon.ico
# - favicon-16x16.png
# - favicon-32x32.png
# - apple-touch-icon.png
# - android-chrome-192x192.png
# - android-chrome-512x512.png
# - site.webmanifest

# - safari-pinned-tab.svg (опционально)
```

### Проверка в браузерах

1. **Chrome/Edge**
   - Откройте DevTools → Application → Manifest
   - Проверьте что manifest загружен
   - Проверьте иконки

2. **Firefox**
   - Откройте DevTools → Storage → Manifest
   - Проверьте favicon во вкладке

3. **Safari**
   - Проверьте pinned tab icon
   - Добавьте на главный экран (iOS)

4. **Мобильные устройства**
   - iOS: Добавьте на главный экран, проверьте иконку
   - Android: Добавьте на главный экран, проверьте иконку

## Рекомендации

### Дизайн

1. **Простота** - favicon должен быть узнаваем даже в маленьком размере
2. **Контраст** - используйте контрастные цвета
3. **Центрирование** - основной элемент должен быть в центре
4. **Отступы** - оставляйте небольшие отступы от краев

### Технические

1. **Формат исходника** - используйте SVG для лучшего качества
2. **Размер исходника** - минимум 512x512px, лучше 1024x1024px
3. **Прозрачность** - используйте прозрачный фон где возможно
4. **Оптимизация** - сжимайте PNG файлы (уже делается в Gulp)

### Обновление

1. **Версионирование** - при обновлении favicon добавляйте версию в URL:
   ```html
   <link rel="icon" href="/favicon.ico?v=2">
   ```

2. **Кеш** - очищайте кеш браузера после обновления

3. **Регулярность** - проверяйте актуальность раз в год через RealFaviconGenerator

## Troubleshooting

### Favicon не отображается

1. Проверьте что файлы скопированы в `build/` после сборки
2. Очистите кеш браузера (Ctrl+Shift+Delete)
3. Проверьте пути в HTML коде
4. Проверьте консоль браузера на ошибки 404

### Неправильный размер на iOS

1. Убедитесь что `apple-touch-icon.png` имеет размер 180x180
2. Проверьте что файл не сжат слишком сильно
3. Используйте RealFaviconGenerator для правильной генерации

### Manifest не загружается

1. Проверьте что `site.webmanifest` валидный JSON
2. Проверьте MIME type на сервере (должен быть `application/manifest+json`)
3. Проверьте пути к иконкам в manifest

### ICO файл не работает в старых браузерах

1. Убедитесь что ICO содержит несколько размеров (16x16, 32x32, 48x48)
2. Используйте RealFaviconGenerator для правильной генерации
3. Проверьте что файл не поврежден
